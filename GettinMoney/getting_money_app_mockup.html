Core rule

Every completed rep creates money. Missed target reps become debt. Money is a reward layer, not a payment method, so the user can only clear debt by doing reps.

money = all completed reps × $1
debt = max(target reps - completed reps, 0)
extra money = max(completed reps - target reps, 0)

Round split

Rounds calculate base target reps per exercise, then distribute any debt payback reps across today’s circles.

base per round = ceil(target / rounds)
payback per round = ceil(today debt payment / rounds)

Progression

Every two weeks the app suggests a small increase. Push-ups and squats scale by 5–10 reps. Pull-ups stay capped at 10 unless manually changed.

new target = target + 5…10
pull-up target ≤ 10 by default
manual override always wins
