# _legacy/

Archived content from before this repo became the iOS App Factory. Preserved, not deleted.

- `README-old-web-system.md` — the previous system's README (web/full-stack orientation).
- The earlier **Next.js web app** (source + config: `app/`, `components/`, `actions/`, `lib/`, etc.).
- App-specific docs/tasks/design/reports from the old single-app layout (e.g. the "Getting Money" planning content), plus `PRODUCT.md` / `DESIGN.md`.

Nothing here is loaded by the active system. Build artifacts (`node_modules/`, `.next/`, `*.tsbuildinfo`) were not archived — they are gitignored and regenerable. Safe to delete this folder once you're sure nothing is needed.
