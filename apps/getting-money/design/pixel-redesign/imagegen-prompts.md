# Imagegen Prompts - Pixel Redesign

## Asset Kit

Mode: built-in `image_gen`

Input image role: reference image for style, density, palette, and asset categories.

Prompt:

```text
Use case: ui-mockup
Asset type: pixel-art mobile app asset and style sheet for an iOS workout game UI
Primary request: Create a polished pixel-art asset sheet for a gamified calisthenics app called Getting Money, inspired by the provided reference board: dark dungeon/gym RPG interface, lime green primary UI, coral debt state, gold coin economy, parchment log cards, merchant banker NPC for debt, hero athlete sprite, and practical mobile controls.
Input images: Image 1 is a reference image for style, UI density, palette, and icon categories; do not copy it exactly.
Style/medium: professional 16-bit pixel art, crisp edges, no flat vector, no photorealism, no gradients except subtle pixel dither texture.
Composition/framing: one organized landscape asset board with labeled sections: color palette swatches, hero sprite front/side/back, banker NPC, paper log card, pixel UI controls, tab icons, exercise icons, progress blocks, primary/secondary CTA examples.
Color palette: near-black #050806, dark surface #10140f, hairline #343829, lime #AEE63D, gold #FFD34D, coral #E85D4F, parchment #E8D8B8, muted stone #9A9485.
Typography: blocky pixel headings; small readable mono labels. Keep text minimal and legible.
Constraints: every visual must be pixel-art styled; include only app-relevant assets: dashboard, log, rounds, debt, settings, push-ups, pull-ups, squats, dips, coin, flame, shield, crossed swords, clipboard, gear, calendar, dumbbell, progress blocks, plus/minus buttons, checkbox, toggle.
Avoid: modern flat vector icons, smooth rounded app-store illustration, glossy 3D, neon glow, extra characters beyond athlete and banker, watermarks.
```
